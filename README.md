
# LLM Non Textuel

Projet : LLM Non Textuel Universel — service de génération de sorties structurées (JSON/CSV/tableaux).  
Stack : FastAPI, Pydantic, LangChain, PostgreSQL, Redis, Docker.

## Structure
- app/ : code source
- config/ : env, settings
- docker/ : Dockerfile, init scripts
- docker-compose.yml
- docs/ : PDF + diagrammes
